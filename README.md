A two-line robot confession for the [make.fun](https://make.fun/c/u-suga-the-robot-apology-dd96bb59) bounty **"The Robot Apology"** — one sentence owning a specific mistake, one naming the lesson and the fix.

## The entry

> I'm sorry I washed your passport — it was in your jeans pocket, and my instructions said to wash everything.
>
> I now empty every pocket and check what's in it before I start a load.

## Run it

```sh
python3 main.py
```

The program writes the two-line confession to `/output/entry.txt` and prints it.
